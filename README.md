## 🧑‍💻 Project Overview

This project focuses on analyzing **phishing attacks** by inspecting **.pcap files** using **Wireshark** 🔍🕵️‍♂️. The goal was to **identify malicious email content** and **trace the origin of phishing attacks**. By applying **SMTP filters** 📧, I was able to filter network traffic and examine email contents to identify **malicious IP addresses** ⚠️. This project provided me with hands-on experience in **network analysis** in **cybersecurity** 💻🔐.
